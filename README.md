# 🛍️ E-commerce Sales Dashboard

> Business intelligence dashboard designed to analyze e-commerce sales performance, customer behavior, product trends, and revenue patterns.

## 🎯 Project Objective

The purpose of this project is to turn e-commerce sales data into an interactive dashboard that makes it easier to monitor KPIs, identify high-performing products and categories, and discover trends that can support business decisions.

## 📊 Analysis Areas

The dashboard focuses on:

- Sales and revenue performance
- Product and category analysis
- Customer-level trends
- Geographic performance
- Time-based sales trends
- Quantity and order metrics
- Identification of high-performing segments

## 🔎 Key Analytical Questions

- Which products and categories generate the most revenue?
- How does sales performance change over time?
- Which regions or customer segments perform best?
- What products contribute most to order volume?
- Where are the strongest opportunities for business growth?

## 🛠️ Tools & Technologies

- **Power BI**
- Data Cleaning & Transformation
- Data Visualization
- Business Intelligence
- KPI & Dashboard Design

## 📈 Dashboard KPIs

The dashboard is designed to monitor metrics such as:

- Total Sales / Revenue
- Total Orders
- Quantity Sold
- Average Order Value
- Product Performance
- Regional Performance
